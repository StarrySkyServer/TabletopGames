# TabletopGames — Nukkit-MOT 休闲游戏合集

## 项目简介

TabletopGames 是一个基于 **Nukkit-MOT** 的桌面/牌桌游戏插件，为 Minecraft 基岩版服务器提供八种游戏：
**五子棋 / 中国象棋 / 黑白棋（奥赛罗）/ 围棋 / 斗兽棋 / 军旗 / UNO / 斗地主**。

棋盘与牌桌由自定义方块 + 单个渲染实体 + 内置资源包绘制，玩家右键放下、入座即玩，
支持机器人 AI、托管代打、断线接管与 EconomyAPI 结算。资源包随插件打包，由服务端自动下发。

## 游戏一览

| 游戏 | 规格 | 人数 | 备注 |
| --- | --- | --- | --- |
| 五子棋 | 15×15，2×2 / 3×3 两种摆放 | 2 | 内置 AI |
| 中国象棋 | 9×10 标准棋盘（32 子） | 2 | xqwlight 引擎 |
| 黑白棋 | 8×8 | 2 | 内置 AI |
| 围棋 | 9 / 13 / 19 路（19 路另有大号 4×4 摆放） | 2 | 内置 AI |
| 斗兽棋 | 标准 7×9 兽棋棋盘（32 子） | 2 | 内置 AI |
| 军旗 | 二国陆战棋 3×3 方块（50 子 + 淘汰托盘） | 2 | 内置 AI |
| UNO | 2~4 人牌桌 | 2~4 | 完整规则，含定庄 / 发牌 / 结算 |
| 斗地主 | 3 人牌桌 | 3 | 叫抢地主、加倍、两档机器人 |

## 功能特性

### 🤖 机器人
- 六种棋类各内置 AI（象棋接入 xqwlight 引擎），**全部在异步线程计算**，不占服务端主线程
- UNO / 斗地主为两档：**初级**（权重打分，毫秒级）/ **高级**（采样推演，秒级）
- **托管、离线、出范围代打一律降级为初级**，避免后台线程堆积
- 斗地主按场次限制加人机：免费场任意；新手/高级场需 ≥2 位真人；大师场只允许 3 位真人

### 👥 对局流程
- 右键棋盘物品放置，按玩家视角自动定向；点击棋盘打开菜单、入座、补人机
- UNO：四家同时抽牌定庄（并列重抽）→ 逐张发牌动画 → 两档出牌倒计时
  （未摸牌默认 20 秒 / 摸牌后默认 15 秒；最后 3 秒红、3~10 秒黄、其余绿）
- 一局结束**不自动收档**：「下一局」投票制；无人事变动时上局赢家连庄、免定庄
- 出牌飞行动画、方向箭头、庄家徽记、回合标记、倒计时与结算板

### 💰 结算（EconomyAPI）
- UNO 按倍数 k 结算（k = 0 为免费局）；实扣 = min(手牌分 × k, 余额)
- 斗地主按场次底分结算：免费场 0 / 新手场 50 / 高级场 800 / 大师场 10000
- 抽水比例可配置，税后全额给赢家；开局前校验余额门槛

### 🔦 定位器
- 入座 UNO / 斗地主时自动发放，离桌回收；手持它右键可稳定上报点击（悬空手牌也能点中）
- **蹲下 + 使用键**切换「屏幕十字准星」（标题层画一个 `+`，每 1 秒续期一次）
- **必须同时满足「手持定位器」和「坐在座位上」才显示**，换手持物品、离座或关掉都立刻消失；
  默认开启，切换有动作栏提示

### ⚙️ 性能与持久化
- **单实体渲染**：整盘棋子 / 整桌牌由一个实体绘制，避免海量实体拖垮服务端
- 状态按位域编码进实体整型属性，一次 `sendData` 同步整桌
- 观战者动画**差量发送**，只发给新进入范围的人
- 八套棋牌共用一个 250ms 调度任务；棋盘/牌桌各自存档（`plugins/TabletopGames/`），重启自动恢复

## 安装要求

| 项目 | 要求 |
| --- | --- |
| 服务端 | Nukkit-MOT |
| Java | 17+ |
| 前置插件 | **EconomyAPI** **OrmLite** |
| 客户端 | 基岩版，进服时需**接受资源包** |

> `plugin.yml` 里声明了 `depend: [EconomyAPI]`，未安装时 Nukkit 直接拒绝加载，
> 不会以「结算不可用」的降级形态运行。

## 构建与安装

```bash
mvn clean package
# 产物：target/TabletopGames-1.0.0-SNAPSHOT.jar
```

1. 把 jar 放进服务端 `plugins/` 目录（**不要在服务运行中覆盖同名 jar**，需重启生效）
2. 启动服务器，首次会自动生成 `plugins/TabletopGames/config.yml`
3. 客户端进服接受资源包（拒绝下载会看不到棋盘/牌桌模型）

> 资源包内置于 jar 的 `assets/resource_pack`。更换过资源内容时必须同时升级
> `manifest.json` 的版本号并更换 header / module 双 UUID，客户端才会重新下载。

## 命令

| 命令 | 说明 | 权限 |
| --- | --- | --- |
| `/tabletopgames` | 打开「全局配置」表单（选游戏 → 进各自配置） | OP |
| `/tabletopgames settings` | 同上 | OP |
| `/tabletopgames reload` | 重载配置文件 | OP / 控制台 |

权限节点：`tabletopgames.command`（默认仅 OP）。

> 棋盘 / 牌桌物品**不再用命令发放**，直接从**创造模式物品栏**取（共 12 件：
> 五子棋 2×2、五子棋 3×3、象棋、斗兽棋、军旗、黑白棋、围棋 9/13/19/19 大号、UNO 牌桌、斗地主牌桌）。
> **定位器不在创造物品栏**——它只在入座 UNO / 斗地主时自动发放，离桌回收。

## 配置

`plugins/TabletopGames/config.yml` 按游戏分八节：`gomoku / xiangqi / othello / go / doushouqi / junqi / uno / ddz`。
每节包含识别半径、菜单独占超时、结算与时间参数等；军旗另有行营斜线 / 无吃子判和手数 / 先手规则，UNO 另有倍数 k、抽水、两档回合时间，
斗地主另有四档底分、倍数上限、发牌节奏。

推荐用 `/tabletopgames` 表单修改（实时生效并写回文件）。手动编辑时注意：多行注释必须是 YAML 数组，
格式错误会导致加载失败——插件会自动把损坏文件备份为 `config.broken-<时间戳>.yml` 并重建默认配置。

## 项目结构

```
src/main/java/com/tabletopgames/
├── TabletopGamesPlugin.java   # 插件入口（实体/方块/物品注册、统一 tick）
├── ai/                      # 各棋 AI、UNO/斗地主 AI、异步调度
├── board/                   # 棋盘 / 牌桌方块
├── command/                 # /tabletopgames 命令
├── config/                  # 配置定义（okaeri-configs）
├── economy/                 # EconomyAPI 接入
├── entity/                  # 棋子 / 牌桌 / 飞牌实体
├── game/                    # 游戏逻辑（各 Manager、UNO/斗地主状态机）
├── item/                    # 棋盘 / 牌桌 / 定位器物品
├── storage/                 # 存档读写
└── ui/                      # 表单菜单
```
